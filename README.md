# ミニ奈々ちゃんと理不尽クエスト

ブラウザで遊べる、ネタ系・高難度2Dアクションゲーム（v0.1）。
ミニ奈々ちゃんが「理不尽クエスト」に挑戦します。AIあるある・発信あるあるを
ネタにした、意地悪だけど笑えるトラップを、覚えて・観察して突破しよう！

> 「なにこれｗ」「また死んだｗ」「でも次はいけるかも」——
> そんなリアクションを目指した、実況・配信向けのミニゲームです。

---

## 概要

- ジャンル: ネタ系・高難度2Dアクション
- 対応: PCブラウザ（キーボード操作）
- 技術: Vite + TypeScript + Phaser 3
- 収録ステージ: 1ステージ「はじめての理不尽」
- 特徴: 即死トラップ／チェックポイント／高速リトライ／死亡回数＆タイム表示／
  クリア評価／SNS共有用テキスト

### 収録ギミック（8種）

| ギミック | 内容 |
| --- | --- |
| ハルシネーション床 | 乗れるように見えて、乗る/近づくと消える床 |
| 生成中足場 | 「生成中…」と点滅し、出たり消えたりする足場 |
| 情報不足ゲート | カギ（情報）を取らないと開かないゲート |
| アルゴリズムの風 | 突風が周期的に吹き、横に押し戻される |
| 炎上コメント弾 | 画面外からコメント風の弾が飛んでくる |
| 納期前ダッシュ床 | 乗ると強制的に走らされる床 |
| やさしい道 | 「初心者向け♪」なのに実はトゲだらけ |
| プロンプト沼 | 入ると移動・ジャンプ力が下がる沼 |

## 遊び方

1. タイトルで「ゲームスタート」を押す
2. ミニ奈々ちゃんを操作してゴールを目指す
3. トラップに当たると即死。でもチェックポイントからすぐ復活！
4. 何度も挑戦して、罠のパターンを覚えれば必ずクリアできます
5. 最後の「やさしいゴール」は **偽物**。本物のゴールは少し手前の上にあります

クリアすると、死亡回数・クリアタイム・評価・SNS共有用テキストが表示されます。

## 操作方法

| 操作 | キー |
| --- | --- |
| 左へ移動 | ← または A |
| 右へ移動 | → または D |
| ジャンプ | Space / W / ↑（押す長さでジャンプの高さが変わります） |
| リトライ | R |
| ポーズ | Esc |

## 開発環境

- [Node.js](https://nodejs.org/) 18 以上（推奨: 20+）
- npm
- Vite 6 / TypeScript 5 / Phaser 3

## ローカルで動かす

```bash
npm install      # 依存パッケージのインストール（初回のみ）
npm run dev      # 開発サーバー起動 → 表示されたURL（例: http://localhost:5173/）を開く
```

## 公開用ビルド

```bash
npm run build    # 型チェック＋本番ビルド。dist/ に静的ファイルが出力される
npm run preview  # ビルド結果をローカルで確認
```

`dist/` の中身をそのままアップロードすれば公開できます。

## 公開方法

`dist/` を静的サイトとして以下のいずれかにデプロイできます。

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

> このプロジェクトは `vite.config.ts` で `base: "./"` を指定しているため、
> サブパス公開（GitHub Pages など）でもそのまま動きます。

## キャラクター画像について

ミニ奈々ちゃんの画像は、ルートにある三面図 `IMG_3798.JPG`（緑背景）を
`scripts/process_character.py`（Python + Pillow）で加工して生成しています。

```bash
python3 scripts/process_character.py
# → public/assets/images/ に nana_front.png / nana_side.png / nana_back.png を出力
```

元画像を差し替えたいときは `IMG_3798.JPG` を入れ替えて再実行してください。

## ファイル構成

```
src/
  main.ts            ゲーム起動
  config.ts          画面サイズ・色・物理パラメータ・テクスチャキー
  scenes/            Boot / Title / Game / Result の各シーン
  objects/           Player・足場・トラップ・チェックポイント・ゴールなど
    gimmicks/        8種のギミック（追加しやすいよう1ファイル1ギミック）
  data/
    stages.ts        ステージ定義（ここを増やすだけで新ステージを追加可能）
    deathMessages.ts 死亡メッセージ集
    texts.ts         セリフ・UIテキスト
  utils/             入力・タイマー・セーブ
public/assets/       画像・サウンド素材（差し替え用）
```

新しいステージは `src/data/stages.ts` にデータを追加するだけで作れます。
新しいギミックは `src/objects/gimmicks/` にクラスを足し、`GameScene` の
ファクトリ（`buildObject`）に分岐を1つ追加すればOKです。

## 素材について

現状、ミニ奈々ちゃん以外（足場・トラップ・ギミック・UI）は、すべて
コード内で描画した図形・テキストのプレースホルダーです。すべてオリジナルで、
既存作品の画像・音楽・キャラクター・ステージ構成・象徴的ギミックは使用していません。
今後、画像や効果音は `public/assets/` に置いて差し替えられます。

## 実況・配信について

**このゲームは実況・配信を歓迎します！**
